## What is GPIO?
* **GPIO** stands for **General Purpose Input/Output**.
* Standard hardware pins on microcontrollers used to interface with external hardware or communication protocols.
* Provides connections for **Power (3.3V / 5V)**, **Ground (0V)**, and **Programmable Pins (Analog / Digital)**.
* Typically dedicated to one device per set of pins unless using a shared bus protocol (e.g., I2C, SPI).
### GPIO Digital Pins

![GPIO Digital Pins](@/assets/images/iot/gpio-digital.png)

#### Digital Input (Reading Signals)
Microcontrollers read external voltages relative to Ground to determine binary states:
* **HIGH (Bit 1):** External voltage is ~3.3V (or 5V, above Ground) → Microcontroller interprets as **1 (HIGH)**.
* **LOW (Bit 0):** External voltage is ~0V (equal to Ground) → Microcontroller interprets as **0 (LOW)**.

#### Digital Output (Controlling Components)
The microcontroller actively drives voltage at the pin based on your code to control connected components (e.g., turning on an LED, triggering a relay, or sounding a buzzer):
* **HIGH (Bit 1):** Connects the pin to the internal power rail → Outputs **3.3V** (or **5V**).
* **LOW (Bit 0):** Connects the pin directly to Ground → Returns to **0V**.

### GPIO Analog Pins
![GPIO Analog Pins](@/assets/images/iot/gpio-analog.png)
* Analog pins can send or receive a range of voltages from 0 to 3.3/5V.
* Input pins use an ADC to convert to a 10-bit number.
* Output pins use an DAC to convert from a 10-bit number.

## I²C - Inter-Integrated Circuit

**I²C** (Inter-Integrated Circuit, pronounced *I-squared-C*) is a synchronous, multi-device serial communication protocol used extensively in IoT applications to connect microcontrollers with sensors, displays, and peripheral chips.

![Inter Integrated Circuit](@/assets/images/iot/4-wires-IC.png)

### Key Features of I²C
* **Controller / Target Architecture:** A **Controller** (formerly *Master*) controls the clock signal and initiates requests, while **Target** (formerly *Slave*) devices respond to requests.
* **Addressable Device Packets:** Every peripheral on the bus has a unique 7-bit (or 10-bit) address. Data is transmitted as addressed packets so only the intended device processes it.
* **Multi-Device Bus:** Multiple sensors can share the exact same two signal lines, saving valuable GPIO pins on the microcontroller.

### The 4 Wires of I²C
An I²C setup requires 4 connections:
* **Power Lines (2 wires):**
  * **VCC:** Power supply (`3.3V` or `5V`).
  * **GND:** Ground reference (`0V`).
* **Signal Lines (2 wires):**
  * **SDA (Serial Data):** Carries bidirectional data packets between devices.
  * **SCL (Serial Clock):** Carries the clock pulses generated by the controller to synchronize data transfer.

### How I²C Communication Works
1. **Start Signal:** The controller initiates communication on the bus.
2. **Address Broadcast:** The controller sends the 7-bit target address plus a Read/Write bit.
3. **Acknowledgment (ACK):** The target matching the address responds to confirm connection.
4. **Data Transmission:** Data bytes are sent sequentially over the **SDA** line, in sync with the **SCL** clock.
5. **Stop Signal:** The controller terminates the communication session, freeing the bus.
